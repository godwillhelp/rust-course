# Курс Rust → Bevy → MMO

Последовательный курс от нуля до сетевой 2D-RPG на Bevy: 59 лекций в пяти модулях, лабораторные, коллоквиумы, экзамены и диплом.

| Модуль | Лекции | Итог |
|---|---|---|
| A. Фундамент | 1–19 | экзамен: консольный Dungeon Crawler |
| B. Продвинутый Rust | 20–31 | экзамен: MUD-сервер, затем **Rust gate** |
| C. Bevy | 32–44 | экзамен: 2D action RPG |
| D. Сеть | 45–54 | экзамен: Online RPG v0.1 |
| E. MMO | 55–59 | диплом |

Bevy начинается только после сдачи Rust gate.

## Как идёт урок

1. Вы пишете «начинаем урок». Я называю тему и задаю разминку: 2 вопроса по прошлой лекции и 1 по более старой.
2. Вы пишете «готов к разбору». Я публикую лекцию и кладу её в `lessons/NN-…/lecture.html`.
3. Вы решаете оба задания, пушите и пишете «сдаю задания лекции N».
4. Я смотрю код и результат CI, задаю 1–2 вопроса на защиту и ставлю оценку. Следующая лекция открывается, когда оба задания сданы.

## Структура

```
Cargo.toml                 workspace: все задания всех лекций
bestiary.md                ваш бестиарий ошибок компилятора
lessons/
  00-setup/                установка инструментов
  01-cargo-variables-numbers/
    README.md              ссылки на лекцию и условия
    lecture.html           лекция (открывается в браузере)
    task1/                 задание с тестами: l01-task1
    task2/                 открытое задание: l01-task2
```

Все команды запускаются из корня репозитория, пакет выбирается флагом `-p`:

```
cargo test -p l01-task1
cargo run -p l01-task2
cargo fmt
cargo clippy --workspace --all-targets
```

## CI

GitHub Actions на каждый push запускает формат (`cargo fmt --check`), сборку, тесты и clippy с `-D warnings`. Пока задания не решены, шаг «Tests» красный: заглушки `todo!()` паникуют. Зелёный CI означает, что все задания проходят тесты и линтер.

## Оценки и XP

Задание — 10 баллов: правильность 4, идиоматичность 2, тесты и граничные случаи 2, объяснение и защита 2. Зачёт от 7 баллов при правильности не ниже 3, иначе пересдача. Подсказки: направление, понятие, фрагмент кода; каждая −1 балл.

XP: баллы задания × 5; лабораторная 150; коллоквиум 100; экзамен модуля 300; Rust gate 500; диплом 1000; новая ошибка в бестиарии +5; найденная ошибка в моей лекции +50; геймджем +200.

Уровни: Crab Egg 0 · Hatchling 300 · Borrow Warrior 1000 · Trait Mage 2400 · Rust Knight 4500 · Bevy Knight 6000 · Netcode Paladin 7200 · Server Lord 8300.

## Правила

- Решения пишутся руками. ИИ-дополнение в редакторе выключено (см. [lessons/00-setup](lessons/00-setup/README.md)).
- Подсказки даю я, по запросу, по лестнице выше.
- Перед сдачей: `cargo fmt`, `cargo clippy --workspace --all-targets`, тесты зелёные.
